## Start project

1. In Part 1, type the project code, application name, and Short description.
2. Finish the later parts, then open Part 5 Save and open.
3. Choose an empty project folder and a coding agent, then click Save and open.
4. If the Short description is blank, the page shows “Write a short description of what the application is.” Go back to Part 1 and fill it.
5. If the Short description is filled, that text is written into the project documents with the rest of the answers (`D-01`).

Write each manual as steps a person can follow on the screen. Update it in the same session as the screen it describes. When a worked example is run, record the date, the inputs, and the ids that were stored.
